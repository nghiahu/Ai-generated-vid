# Design Doc: Integrate Remotion Agent Skills

Documenting the integration of the official `remotion-dev/skills` package into this repository.

## Problem Statement

When writing React code for Remotion, AI coding agents need specialized domain guidelines (such as frame-based timing, composition design, and avoiding non-deterministic web features like standard CSS transitions). 

We want to import the official `remotion-best-practices` agent skill into this project's local configuration.

## Proposed Integration

Rather than keeping extraneous directories generated by the CLI, we:
1. Fetch/download the `remotion-best-practices` skill from the official `remotion-dev/skills` repository.
2. Copy it into the `.agent/skills/remotion-best-practices` directory of this project so it is tracked in Git and used by Antigravity.
3. Clean up the other generated dotfolders (`.continue`, `.roo`, `.devin`, etc.) to keep the project workspace tidy.

## Verification

- The skill file `.agent/skills/remotion-best-practices/SKILL.md` is present and readable.
- Git status shows only the relevant `.agent/skills/remotion-best-practices/` untracked files.
