# Sprint 3 — Director Engine: End-to-End Pipeline Proof

**Date:** 2026-07-29
**Goal:** Prove Director Engine can replace the old pipeline end-to-end with no hardcoded data.

## Deliverable

A single executable path:

```
User inputs script
        ↓
POST /api/aigen/director
        ↓
DirectorManifest (generated by 2-pass Semantic Planner)
        ↓
Persist to DB
        ↓
GET /api/aigen/director/:projectId → manifest.json
        ↓
Remotion Studio inputProps → DirectorRoot → Video
```

**Golden Demo checklist:**
1. Input script → POST API → manifest generated
2. Refresh / curl GET → manifest still exists in DB
3. Copy JSON → Remotion Studio props → render → same video as before

## Architecture Decisions

### Decision 1: Backend API is separate from Render
- POST generates the manifest and persists it
- GET only returns the manifest; no LLM calls
- Frontend (Remotion Studio) is the "renderer" — it only reads the manifest
- This decouples "generation" from "rendering" permanently

### Decision 2: 2-pass Semantic Planner (designed for future 3-pass)

```
Script
  │
  ├─ pre-split (backend, no LLM)
  │     paragraphs[] = script.split('\n\n').filter(Boolean)
  │
  ▼
[Pass 1: Narrative + Scene Planner]
  │  Input : fullScript + paragraphs[] (numbered)
  │  Output: SceneSkeleton[]
  │
  ▼
SceneSkeleton[]
  │
  ▼
[Pass 2: Intent + Content Planner]
  │  Input : skeleton + script.slice(paragraphIds) + prev/next scene context
  │  Output: SceneIntent + SceneContent
  │
  ▼
DirectorManifest
```

### Decision 3: sourceRange uses paragraphIds (not character offsets)

```typescript
interface SceneSkeleton {
  id: string;
  narrativeMoment: 'opening' | 'rising' | 'peak' | 'falling' | 'closing';
  summary: string;
  paragraphIds: number[];
  estimatedDuration: number;
  dependencies: string[];
}
```

### Decision 4: Frontend = Remotion Studio (no custom UI for Sprint 3)

### Decision 5: DB uses existing `projects` table with type='DIRECTOR'

## API Contracts

```
POST /api/aigen/director
Body: { script, theme?, fps?, width?, height? }
Response: { success, projectId, manifest }

GET /api/aigen/director/:projectId
Response: { projectId, manifest }

GET /api/aigen/director/:projectId/export
Response: manifest.json file download
```
