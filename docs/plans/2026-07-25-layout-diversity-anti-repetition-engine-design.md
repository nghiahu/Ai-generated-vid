# Design: Layout Diversity Anti-Repetition Engine v2

**Date:** 2026-07-25  
**Status:** Approved  
**Topic:** Fix layout monotony where 4/5 scenes in a video all render as "dark card + numbered list" despite different `visualPattern` names. 3-layer fix: diversified safety net fallbacks, full-video slot rotation, and Gemini pattern compliance enforcement.

---

## 1. Problem Statement

A 5-scene video generated by Studio AI Gen consistently has:
- Scenes 1, 2, 4, 5 → all visually render as "dark card with numbered 01/02/03 list + large header"
- Only scene 3 (middle) occasionally differs

### Root Cause 1: Safety Net Fallback always renders numbered card list
When Gemini TSX fails to compile, `generateGlassCardSafetyNetTSX()` is called. This function ALWAYS generates the same numbered card list layout regardless of `scene.visualPattern`. Multiple scenes hitting this fallback → identical visuals.

### Root Cause 2: Rotation only prevents consecutive duplicates
Post-processing rotation only ensures scene `i` != scene `i-1`. For 5 scenes, patterns like `BULLET_GLASS → TITLE_HOOK → BULLET_GLASS → TITLE_HOOK → BULLET_GLASS` are allowed — scenes 1, 3, 5 all look the same.

### Root Cause 3: Gemini drifts away from assigned pattern structure
Gemini ignores the pattern skeleton spec and renders numbered card lists for patterns that should look completely different (e.g. TITLE_HOOK = giant heading, no cards).

---

## 2. Architecture: 3-Component Fix

### Component A — Diversified Safety Net Fallback

Refactor `generateGlassCardSafetyNetTSX(scene)` → `generateSafetyNetTSX(scene)` that dispatches to 6 distinct hardcoded templates based on `scene.visualPattern`:

| Pattern | Fallback Visual |
|---|---|
| `BULLET_GLASS` | Numbered card list (current) |
| `TITLE_HOOK` | Full-screen centered heading + glowing capsule badge. NO cards |
| `HERO_METRIC_GLOW` | Giant number (120px) centered with radial orange glow |
| `DUAL_METRIC_CARDS` | 2 side-by-side metric cards in CSS 2-column grid |
| `COMPARISON_VERSUS` | 2-column VS layout with left/right panels |
| `PROCESS_TIMELINE` | 3-step vertical chain with gradient connector lines |
| *(all others)* | TITLE_HOOK fallback |

All templates are pure JS string literals — zero AI dependency.

### Component B — Full-Video Pattern Slot Assignment

Add `assignPatternSlots(sceneCount)` returning a deterministic, non-repeating pattern sequence:

- Scene 0 → always TITLE_HOOK (opening hook)
- Scene N-1 → always ENDING_CTA (if N >= 3), else HERO_METRIC_GLOW
- Middle scenes → pulled from shuffled pool, no repeats

Inject pre-assigned slots into `generateScenePlanForAIGen` userPrompt as MANDATORY directive. Post-processing rotation becomes a validator (not reassigner).

### Component C — Gemini Pattern Compliance Lock

**C1 — Pattern Lock Header in Phase 2 Prompt**: Add explicit per-scene lock at TOP of systemInstruction:
```
LOCKED VISUAL PATTERN: DUAL_METRIC_CARDS
You MUST render EXACTLY: 2 side-by-side metric cards (CSS grid 1fr 1fr).
You MUST NOT render any numbered list, bullet points, or card stacks.
```

**C2 — Pattern Compliance Validator**: Add `validatePatternCompliance(tsxCode, visualPattern)` with heuristic checks:
- TITLE_HOOK: must NOT contain numbered badges (01/02/03)
- DUAL_METRIC_CARDS: must contain `gridTemplateColumns`
- HERO_METRIC_GLOW: must contain large fontSize (>= 100px)
- COMPARISON_VERSUS: must contain VS or 2-column grid
- BULLET_GLASS: must contain numbered badges

If validation fails → skip AI output, use `generateSafetyNetTSX(scene)` directly.

|---|---|
